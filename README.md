# 📊 Sales Analysis Excel Dashboard

## 📌 Project Overview

This project showcases an interactive **Sales Analysis Dashboard developed using Microsoft Excel**. The dashboard was created as a personal learning project to strengthen practical skills in data analysis, dashboard development, and data visualization.

The dataset contains **1,000+ sales records** and provides insights into sales performance across different cities, products, categories, sales representatives, and months.

## 🎯 Project Objectives

* Analyze overall sales performance using Microsoft Excel.
* Identify sales trends across different months and cities.
* Compare product-wise and category-wise sales performance.
* Analyze sales representative performance.
* Develop an interactive and visually organized sales dashboard.
* Practice business-oriented data analysis and reporting.

## 📊 Dashboard Features

The dashboard enables users to analyze:

* Sales by City
* Product-wise Sales
* Category-wise Sales
* Sales by Sales Representative
* Month-wise Sales Trends

Interactive slicers allow users to filter data and explore specific time periods and sales segments.

## 🔄 Project Workflow

**Raw Sales Data → Data Preparation → Pivot Tables → Pivot Charts → Slicers → Dashboard → Sales Analysis**

# Sales Analysis Excel Dashboard

## Project Overview

This project showcases an interactive sales analysis dashboard created using Microsoft Excel. The dashboard was developed as a personal learning project to practice data analysis, dashboard design, and data visualization techniques.

The dataset contains over 1,000 sales records and provides insights into sales performance across different cities, products, categories, sales representatives, and months.

## Dashboard Features

The dashboard enables users to analyze:

* Sales by City
* Product-wise Sales
* Category-wise Sales
* Sales by Sales Representative
* Month-wise Sales Trends

Interactive slicers allow users to filter data and explore specific time periods.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualization Techniques

## Key Insights

The dashboard helps identify:

* Top-performing cities
* Best-selling products
* Highest revenue-generating categories
* Sales representative performance
* Monthly sales trends

The project uses a sales dataset containing over 1,000 records with fields such as:
